# 勤怠入力省力化Webアプリ 要件定義

## 1. 背景・目的

### 現状 (AS-IS)

- 勤怠入力のためにPCを開き、Excel（`勤務報告書2026年度（0246竹森千馬）.xlsm`）に直接入力する必要がある。
- スマホからでもExcelは開けるが、セル結合・数式・ドロップダウンが多く編集しづらい。
- 結果として月末にまとめて入力することになり、記憶が曖昧なまま埋める・時間がかかる。

### 改善後 (TO-BE)

- スマホのWebアプリから、その日のうちに数タップで勤怠を記録できる。
- 通勤時間などのスキマ時間で入力でき、月末の一括入力の手間がなくなる。
- 月末は、アプリが出力したTSVをExcelの `年間入力シート` に貼り付けるだけで完了する。

---

## 2. スコープ

| | 内容 |
|---|---|
| 対象 | 勤怠データの日次入力・修正、月次TSVの出力とインポート |
| 対象外 | 月度シート（`4月度` 等）の生成。Excel側のVBA「勤務報告書作成」ボタンの責務 |
| 対象外 | Excelファイル自体の読み書き（.xlsm生成／マクロ実行）。連携はクリップボード経由の貼り付けとする |

---

## 3. 前提・制約

- Webアプリであること（スマートフォンからの利用を前提とする）。
- DBを使用しない。データはブラウザの LocalStorage に保持する（インフラ最小化）。
- フロントエンドのみで完結し、バックエンド通信を行わない。
- 静的ホスティング（GitHub Pages 等）で配信できること。
- オフラインでも起動・入力・保存ができること。

---

## 4. 連携先Excelの概要

貼り付け先は `年間入力シート` の1シートのみ。年度の全日付が1日1行であらかじめ並んでおり、アプリは**対象月の範囲に、勤怠区分・開始・終了・休憩・作業内容・備考を貼り付ける**。

貼り付けにあたっては以下の制約がある。

- 実働時間と振休残の列は**数式**のため上書きしてはならない。
- 作業内容・備考の列は**セル結合**されている。
- 勤怠区分は**7区分**（通常勤務 / 休日勤務 / 午前半休 / 午後半休 / 休暇 / 振休 / その他休）のドロップダウンで固定。
- 勤務時間は**15分単位**、「開始」は原則**始業時間**を入力するという運用ルールがある。

この制約により、TSVは1ブロックではなく**複数ブロックに分割**して貼り付ける方式をとる。

> 列構成・行番号の算出・数式・祝日マスタ・TSVの詳細な書式は **`doc/excel-format.md`** を参照。

## 5. 機能要件

### F-1. 日次入力

- 対象日（デフォルトは当日）に対し、勤怠区分・開始・終了・休憩・作業内容・備考を入力する。
- スマホでの入力負荷を下げるため、以下を満たす。
  - 入力コントロールはタップ主体（区分はボタン、時刻は15分刻みのピッカー）。
  - 既定の勤務パターン（F-6）から時刻を自動セットする。
  - 「今日を通常勤務で登録」のワンタップ操作を用意する。
- 実働時間（終了 − 開始 − 休憩）をリアルタイム表示する。

### F-2. 過去データの修正

- 月カレンダー／リストから任意の日を選び、入力・修正・削除ができる。
- 未入力日が一目でわかること。土日祝は休日として区別表示する。

### F-3. 月次データのエクスポート（TSV）

- 対象月を選ぶと、`年間入力シート` に貼り付けるためのTSVを生成し、クリップボードにコピーする。
- **貼り付け先セル番地を画面に明示する**（例: 「5月度 → `C43` に貼り付け」）。
- 数式列とセル結合を壊さないよう、ブロックを分けて順にコピーできるUIとする。
- 未入力日は空行として出力し、行ズレを起こさない。
- クリップボードAPIが使えない環境向けに、TSVをテキストエリアに表示して手動選択できるフォールバックを用意する。

### F-4. 月次データのインポート

- Excelの `年間入力シート` からコピーしたTSVを貼り付けてアプリに取り込める（機種変更・PC入力分の取り込み）。
- 既存データがある日は差分をプレビューし、上書きの可否を確認してから確定する。

### F-5. データ管理

- 全データを LocalStorage に保存する（年度単位でキーを分離）。
- 全データのJSONエクスポート／インポート（バックアップ・端末移行用）。
- ブラウザデータ削除で消える旨を画面に明示する。

### F-6. 設定

- 既定の勤務パターン（開始 09:30 / 終了 18:30 / 休憩 1:00 など）。
- 年度（デフォルト 2026年度 = 2026/4/1〜2027/3/31）。
- よく使う作業内容・備考のプリセット登録（例: `AIプロダクト（自宅）`、`★草加↔築地`）。

### F-7. 集計表示（補助）

- 対象月の合計実働時間、勤務日数、区分別日数を表示する。
- 振休残の推移を表示する（Excelと同じロジック）。

---

## 6. 非機能要件

- **表示**: スマホ縦画面（375px幅）で横スクロールなしに操作できること。
- **軽量**: 初回ロードが低速回線でも実用的なサイズに収めること。成果物は静的ファイルのみ。
- **オフライン**: 一度読み込めばオフラインで起動・入力できること。
- **データ保全**: 入力は即時保存し、画面遷移やアプリ終了で失われないこと。
- **プライバシー**: 氏名・所属・勤務実績を外部送信しない（バックエンドを持たない設計により担保）。
- **対応ブラウザ**: iOS Safari / Android Chrome の最新版。

---

## 7. バリデーション

| 項目 | ルール |
|---|---|
| 時刻の粒度 | 15分単位。外れる場合は警告 |
| 開始 < 終了 | 満たさない場合はエラー |
| 実働時間 | 負値になる場合（休憩が長すぎる）はエラー |
| 勤怠区分 | 定義された7区分以外は不可 |
| 休日勤務 | 対象日が平日の場合は警告 |
| 通常勤務 | 対象日が土日祝の場合は警告 |
| 休暇／その他休 | 開始・終了・休憩は空を推奨（入力があれば確認） |
| 未入力日 | 平日かつ未入力の日はエクスポート時に一覧で警告 |

---

## 8. 想定利用フロー

1. **日次**: 帰宅時にその日のカードを開き、既定パターンのまま「登録」。作業内容だけプリセットから選ぶ。
2. **随時**: 忘れた日はカレンダーの未入力マークから遡って入力。
3. **月末**: 対象月を選び、警告（未入力・15分粒度違反）を解消してから「TSVをコピー」。
4. PCでExcelを開き、`年間入力シート` の指定セルに貼り付ける。
5. Excelの「勤務報告書作成」ボタンで月度シートを生成し、提出する。
