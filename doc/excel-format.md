# 貼り付け先Excel仕様

対象ファイル: `resources/勤務報告書2026年度（0246竹森千馬）.xlsm`

アプリが生成するTSVの貼り付け先となるExcelブックの構造をまとめる。
要件の概要は `doc/requirements.md`、アプリ側の設計は `doc/architecture.md` を参照。

---

## 1. シート構成

| シート | 役割 | アプリとの関係 |
|---|---|---|
| 年間入力シート | 年度全日分の勤怠を1日1行で入力する原本 | **貼り付け先。アプリの対象** |
| ＜入力時使用しません＞ | 月度シートのテンプレート | 対象外 |
| 4月度 / 5月度 / … | 提出用の月次帳票 | 対象外（VBA「勤務報告書作成」ボタンで年間入力シートから生成される派生物） |

アプリは `年間入力シート` にのみ関与する。月度シートの生成はExcel側のVBAの責務。

---

## 2. `年間入力シート` のレイアウト

### 2.1 行の構成

- ヘッダ行: **12行目**
- データ行: **13行目 〜 377行目**（365行）
- 年度の全日付（2026/4/1〜2027/3/31）がB列に**あらかじめ埋まっている**。日付を書き込む必要はなく、行番号がそのまま日付に対応する。

行番号の算出式:

```
行番号 = 13 + (対象日 − 年度開始日(4/1)) の日数差
```

月初の行番号（2026年度）:

| 月度 | 開始行 | 月度 | 開始行 |
|---|---|---|---|
| 4月 | 13 | 10月 | 196 |
| 5月 | 43 | 11月 | 227 |
| 6月 | 74 | 12月 | 257 |
| 7月 | 104 | 1月 | 288 |
| 8月 | 135 | 2月 | 319 |
| 9月 | 166 | 3月 | 347 |

### 2.2 列の構成

| 列 | 項目 | 書式 | 性質 | アプリからの出力 |
|---|---|---|---|---|
| B | 月日 | `m/d(aaa)` | 入力済み | **出力しない** |
| C | 勤怠区分 | General | 入力規則（ドロップダウン7値） | 出力する |
| D | 開始 | `h:mm` | 時刻 | 出力する |
| E | 終了 | `h:mm` | 時刻 | 出力する |
| F | 休憩 | `h:mm` | 時刻 | 出力する |
| G | 時間 | `h:mm` | **数式** | **出力しない（上書き厳禁）** |
| H〜J | 作業内容(作業場所) | — | 行ごとに `H:J` が**セル結合** | 出力する（H列単独） |
| K〜L | 備考 | — | 行ごとに `K:L` が**セル結合** | 出力する（K列単独） |
| N | （非表示列） | General | 曜日コード（10=日 〜 70=土）。条件付き書式の土日色分け用 | 出力しない |
| O | 振休残 | `[hh]:mm` | **数式**（前行から繰り越し累積） | 出力しない |

### 2.3 数式

G列（実働時間）:

```
=IF(AND(D13<>"",E13<>""),E13-D13-F13,"")
```

O列（振休残・前行からの累積）:

```
=IFS(
  C13="休日勤務", O12+G13,
  AND(C13="振休", NOT(G13="")), O12-TIME(8,0,0)+G13,
  AND(C13="振休",     G13=""), O12-TIME(8,0,0),
  TRUE, O12
)
```

- 休日勤務: 実働時間を加算
- 振休（一部勤務あり）: 8時間を減算し実働時間を加算
- 振休（終日）: 8時間を減算
- 起点は `O13 = 2:10:00`（前期引き継ぎ、`P13` に注記）

## 3. 勤怠区分（C列の入力規則）

C13:C378 にリスト形式の入力規則が設定されており、以下の7値のみ許容される。アプリの選択肢も**この文字列と完全一致**させること。

| 値 | 意味（シート内 U3:V9 の凡例） |
|---|---|
| 通常勤務 | 始業時間から終業時間まで勤務したとき |
| 休日勤務 | 土日祝日、会社が定める休日に出勤したとき |
| 午前半休 | 1日のうちの前半4時間の休暇を取得したとき |
| 午後半休 | 1日のうちの後半4時間の休暇を取得したとき |
| 休暇 | 年次有給休暇を取得したとき。有給は無いが休んだとき。 |
| 振休 | 1日のうち一部でも振替休暇を取得したとき |
| その他休 | 夏季休暇、慶弔休暇、常駐先の休暇など |

### 4.2 月度期間マスタ（`P54:R66`）

月度と作成期間（From/To）の対応表。`D8`（作成月）の入力規則および `G8`/`I8` のVLOOKUPで参照される。月度は暦月と一致する（4月度 = 4/1〜4/30）。

## 5. TSV貼り付け仕様

### 5.1 分割コピーが必要な理由

C〜K列を1ブロックでコピーすると、以下の2点を壊してしまう。

1. **G列の数式**が値で上書きされる
2. **H:J / K:L のセル結合**とブロックの形状が一致せず、Excelが貼り付けを拒否する

そのため、連続かつ結合のない領域ごとに**3ブロックに分割**して貼り付ける。

### 5.2 ブロック定義

| ブロック | 列数 | 貼り付け先 | 内容 |
|---|---|---|---|
| ① 勤務時間 | 4列（C〜F） | `C{開始行}` | 勤怠区分 / 開始 / 終了 / 休憩 |
| ② 作業内容 | 1列（H） | `H{開始行}` | 作業内容(作業場所) |
| ③ 備考 | 1列（K） | `K{開始行}` | 備考 |

`{開始行}` は 2.1 の算出式による対象月の初日の行番号。

### 5.3 TSVの書式

- 区切り文字: タブ (`\t`)
- 改行: `\r\n`（Excel貼り付け互換）
- 行数: 対象月の日数と一致させる。未入力日も**空行として出力**し、行ズレを防ぐ
- 時刻: `9:30` 形式（`h:mm`、ゼロ埋めなし）。Excelが時刻値として解釈する
- 空欄: 空文字（タブは維持）
- 値にタブ・改行を含めない（作業内容・備考は入力時にサニタイズする）

### 5.4 出力例（5月度・①ブロック・冒頭3行）

```
通常勤務	9:30	18:30	1:00
		
休日勤務	10:00	15:00	0:00
```

貼り付け先: `C43`

## 6. Excel側の運用ルール（シート内注意書き `U15:U20`）

- 現場都合や上長の指示・承認がある場合を除き、「開始」は**始業時間**を入力する。
- 過去の月のタブは、蓄積する形で作成する。
- 必ず `年間入力シート` に入力の上、「勤務報告書作成」ボタンから月度シートを作成する。
- **勤務時間は15分単位**とする。

---

## 7. 検証が必要な事項

- 結合セル（H:J、K:L）に対する複数行TSV貼り付けの挙動。Excelのバージョンによっては「この操作は結合セルには行えません」で拒否される可能性がある。拒否される場合は、②③を1行ずつコピーするモードにフォールバックする。
- 時刻文字列 `9:30` の貼り付けが、既存のセル書式 `h:mm` を保ったまま時刻値として解釈されるか。
